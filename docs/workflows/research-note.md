# Research Note Workflow

Use when the user asks to turn a market observation, trading concept, or source document into a reusable note.

## Source Priority

1. `canonical rulebook/` for approved rules.
2. `vault raw sources/` for raw source material.
3. User-provided notes or external references.

Raw source material is not a production trading rule until explicitly reviewed and promoted.

## Steps

1. Clarify the research question.
2. Read only the relevant source/refined files.
3. Summarize the observation.
4. Separate rule-backed conclusions from open hypotheses.
5. List conflicts or missing evidence.
6. Propose rule-promotion candidates only when the user asks for that.

## Output Shape

Required sections:

- 研究问题
- 证据来源
- 规则支持
- 未验证假设
- 可复用结论
- 后续验证

## Boundary

Do not update `canonical rulebook/` from a research note unless the user explicitly asks for a reviewed rule promotion.
